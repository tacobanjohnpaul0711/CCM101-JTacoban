1 Mission Overview
The mission/activity was about learning and using basic Linux commands in the terminal. The goal was to become familiar with the Linux environment and learn how to navigate directories, check system information, and create and manage files and folders using the command line.

2. Objectives
Learn how to use basic Linux commands.
Check the current directory and user account.
Learn how to navigate through different directories.
Create and manage files and folders.
Practice using the Linux terminal.
Understand the basics of the Linux file system and command-line operations.

3. Activities Performed
During the activity, I opened the Linux terminal and used different commands. First, I checked the current working directory and the name of the logged-in user. I also checked the hostname of the computer and viewed the files and folders in the current directory.
I navigated through different directories using the cd command. I created a new directory using mkdir and created a new file using touch. I also used the cat command to view the contents of a file. Through these activities, I practiced basic file management and directory navigation in Linux.

4. Linux Commands Used
pwd – displays the current working directory.
whoami – displays the current logged-in user.
hostname – displays the name of the computer or system.
ls – lists files and directories.
cd – changes the current directory.
mkdir – creates a new directory.
touch – creates a new file.
cat – displays the contents of a file.

5. Skills Learned
Basic Linux command-line navigation.
Using the terminal to check system information.
Basic file and directory management.
Creating files and folders using Linux commands.
Viewing the contents of files.
Improved familiarity with the Linux terminal.
Better understanding of the Linux file system and command-line interface.
